# 4 รู้ สู่ความมั่งคั่ง — Index

## Session Overview

หลักสูตร **Financial Literacy 101** ย่อยเรื่องการวางแผนการเงินส่วนบุคคลออกเป็น 4 ขั้น
เนื้อหาต้นทางมาจาก **ตลาดหลักทรัพย์แห่งประเทศไทย (SET)** ปรับใช้โดยทีม Wealth & Private Bank ของธนาคารกรุงเทพ

> แก่นของ session: "ไม่ว่าเราจะชอบหรือไม่ชอบ เข้าใจหรือไม่เข้าใจ ชีวิตเราเกี่ยวข้องกับเรื่องเงินตั้งแต่เกิดจนถึงวันสุดท้ายของชีวิต — ถ้ามีวิธีวางแผนและบริหารที่ถูกต้อง ชีวิตจะง่ายขึ้นเยอะ"

## Key Numbers (Quick Reference)

| ตัวเลข | ความหมาย |
|--------|----------|
| **10–20%** | สัดส่วนของรายได้ที่ควรออมก่อนใช้ |
| **3–6 เท่า** | เงินสำรองฉุกเฉิน (เท่าของรายจ่ายต่อเดือน) |
| **45%** | เพดานภาระผ่อนหนี้รวมต่อเดือนต่อรายได้ |
| **25% / 20%** | เพดานย่อย: หนี้บ้าน / (บัตรเครดิต + รถ) |
| **~3%** | อัตราเงินเฟ้อโดยประมาณที่ใช้อ้างอิงใน session |
| **7–14 วัน** | ระยะเวลารอคิดก่อนซื้อของชิ้นใหญ่ |
| **500 บาท** | ขั้นต่ำการลงทุน B-WEALTH Series |
| **23,195 บาท** | ผลรวมออมตามเลขท้าย 3 ตัว ตลอดปี 2568 |
