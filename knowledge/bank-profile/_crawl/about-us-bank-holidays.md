| วันอังคาร | 3 มีนาคม | วันมาฆบูชา |
| วันจันทร์ | 6 เมษายน | วันพระบาทสมเด็จพระพุทธยอดฟ้าจุฬาโลกมหาราช และวันที่ระลึกมหาจักรีบรมราชวงศ์ |

| วันจันทร์ | 1 มิถุนายน | ชดเชยวันวิสาขบูชา (วันอาทิตย์ที่ 31 พฤษภาคม 2569) |
| วันพุธ | 3 มิถุนายน | วันเฉลิมพระชนมพรรษาสมเด็จพระนางเจ้าสุทิดา พัชรสุธาพิมลลักษณ พระบรมราชินี |
| วันอังคาร | 28 กรกฎาคม | วันเฉลิมพระชนมพรรษาพระบาทสมเด็จพระเจ้าอยู่หัว |
| วันพุธ | 29 กรกฎาคม | วันอาสาฬหบูชา |
| วันพุธ | 12 สิงหาคม | วันเฉลิมพระชนมพรรษาสมเด็จพระนางเจ้าสิริกิติ์ พระบรมราชินีนาถ พระบรมราชชนนีพันปีหลวง และวันแม่แห่งชาติ |
| วันอังคาร | 13 ตุลาคม | วันนวมินทรมหาราช |
| วันศุกร์ | 16 ตุลาคม | วันหยุดทำการเพิ่มเป็นกรณีพิเศษในพื้นที่กรุงเทพมหานคร |
| วันศุกร์ | 23 ตุลาคม | วันปิยมหาราช |
| วันจันทร์ | 7 ธันวาคม | ชดเชยวันคล้ายวันพระบรมราชสมภพ พระบาทสมเด็จพระบรมชนกาธิเบศร   มหาภูมิพลอดุลยเดชมหาราช บรมนาถบพิตร วันชาติ และวันพ่อแห่งชาติ   (วันเสาร์ที่ 5 ธันวาคม 2569) |
| วันพฤหัสบดี | 10 ธันวาคม | วันรัฐธรรมนูญ |

สำหรับสาขาของธนาคารพาณิชย์ในพื้นที่จังหวัดนราธิวาส ปัตตานี ยะลา สตูล และสงขลา ให้หยุดในวันตรุษอีดิ้ลฟิตรี (วันรายอปอซอ) และวันตรุษอีดิ้ลอัฎฮา (วันรายอฮัจยี) ตามประกาศสำนักจุฬาราชมนตรี และวันตรุษจีน เป็นการเพิ่มเติม หากวันดังกล่าวไม่ตรงกับวันหยุดตามที่กล่าวข้างต้นหรือวันหยุดประจำสัปดาห์
